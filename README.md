## About Me

안녕하세요. 데이터 분석과 AI 모델링을 기반으로 문제를 정의하고 해결하는 데이터 사이언티스트 임형섭입니다.

이전에는 다양한 데이터 기반 프로젝트를 경험하며 **머신러닝, 딥러닝, 데이터 처리, 모델링, 서비스 구현 흐름**을 학습하고 적용해왔습니다.  
현재는 그 경험을 바탕으로 **계산독성학(Computational Toxicology)** 분야에서 QSAR와 딥러닝 기반 독성 예측 모델을 개발하고, 이를 실제 SaaS 서비스에서 사용할 수 있는 구조로 연결하는 데 집중하고 있습니다.

저는 단순히 모델을 만드는 것보다, 데이터 입력부터 모델 추론, 결과 저장, 해석, 리포트 생성까지 이어지는 **재현 가능하고 운영 가능한 AI 서비스 구조**를 설계하는 데 관심이 있습니다.
